# Monsieur Buongiorno website

A static editorial home for Albert Ching. Deploy to Netlify with the publish directory set to the repository root.

## Publishing

- Edit `index.html` to change homepage copy, selections, and links.
- Add articles as standalone HTML pages under `articles/`, then link them from the homepage and add their URLs to `sitemap.xml`.
- Keep disclosures beside recommendations with affiliate links.
- The newsletter currently links to the existing Substack.

This repository is separate from Maison Buongiorno’s storefront.
